# ADR 0006: Jump 0.3 hardening

Status: accepted local contract (2026-10-03); rollout blocked.
Extends ADR 0005 without rewriting historical decisions or evidence.

## Decision

Service version is 0.3.0; JWT schema remains 1, exact `rpl=reuse`, ES384/P-384,
13 canonical nodes and exactly 20 directed edges. Jump remains stateless.
The inbound structural TTL maximum becomes 30 seconds rather than 300; this is
schema-1 acceptance tightening for least privilege. Clock tolerance remains
five seconds for current-time comparisons only. Fractional NumericDates remain
supported. Outbound TTL stays 30 seconds; no receiver-config negotiation occurs.

Native observability, logs, invocation logs and traces are enabled, with 100%
sampling and native persistence. Query strings are redacted. Protocol values
must never be transported in pathnames. Platform pathname/generated metadata
persistence is accepted operational risk; application logs keep their existing
allowlist/redaction and forbidden-value rules. External export and retention
beyond Cloudflare native retention are deferred.

pnpm 12 configuration must be verified using the pinned executable, config get
and local help/schema. Disable automatic pnpm download/switch via `pmOnFail:
error`; deny lifecycle scripts via `ignoreScripts: true` while retaining
`allowBuilds`. Preserve registry and minimum release age. Do not newly enforce
Node engine policy. Dependency fixes prefer compatible parent updates over
scoped/exact overrides; never ignore audit or globally disable release age.

## Consequences and unchanged decisions

Tokens over 30 seconds reject even if otherwise signed and within time skew.
Canonical issuers reportedly already use at most 30 seconds; live issuer proof
remains external. Receiver WHATWG URL binding is not weakened to Rack semantics.
Rails URL comparison and receiver TTL fixes remain external release blockers,
as do GitHub required-check enforcement, production bindings/traffic and a real
rollback-compatible immutable Worker artifact.

Keep the key lifecycle: one non-extractable active private key and active kid,
explicit active/grace/future public JWKS, active pair probe, prepublish/activate/
retire, measured grace, B-compatible recovery and conditional old-private
clearance. Compromise requires receiver revocation without grace; JWKS removal
alone is insufficient. No runtime private-to-public fallback is introduced.

Signer-failure cache, malformed-JWKS negative cache and broad retry redesign are
deferred. Node 24 versus typings 26 and prerelease Miniflare are accepted scope
boundaries unless an actual package defect is identified. The undici advisory
beneath Miniflare remains a separate remediation obligation.
