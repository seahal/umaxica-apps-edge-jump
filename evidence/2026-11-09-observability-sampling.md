## Verification method and limitations

Inspected all tracked handwritten wrangler.jsonc files and all explicitly declared environments. Production means the top-level configuration (`--env ''`), not an invented named production environment. No undeclared environments were synthesized. No production or remote deployment, dashboard/API change, or commit was performed.

For each of the 91 deployed Worker/environment combinations, ran a local `wrangler deploy --dry-run` and read the JSON `metadata` part of the multipart upload generated by `--outfile /tmp/...`. Only Observability fields were extracted for this record. Values below are actual dry-run upload metadata, not inferred from source text.

Wrangler versions: Edge 4.148.0, Jump 4.152.0, Away 4.145.0. The installed pnpm launcher could not access its read-only engine-store lock. Commands therefore ran through `pnpm with current --config.verifyDepsBeforeRun=false` (pnpm 12.15.0), using a temporary pnpm wrapper for nested scripts; no replacement was downloaded. This differs from repository pins. Node was v26.12.0, also different from the repositories' pinned 24.x versions. Dependency auto-install was disabled for subsequent commands after the Edge Intent command attempted installation and failed on the read-only store. The installed Intent command is missing; no replacement was downloaded.

Modes:

- **J**: ordinary Jump dry-run, bundled original entrypoint, explicit temporary outdir/outfile. Both passed.
- **E**: Edge metadata-only dry-run: `pnpm exec wrangler deploy --config <unit>/wrangler.jsonc --env <env> --dry-run --no-bundle --assets <unit>/dist/client --outdir /tmp/<unique> --outfile /tmp/<unique>.multipart`. Original handwritten config, existing client assets; assets are a CLI-only verification override. Without it the input config fails because Vite normally supplies assets.directory. Bundling was skipped; existing dist may be stale. This validates environment resolution and outgoing Observability metadata, **not a fresh build or deployable application bundle**.
- **N**: Busy/Away metadata-only dry-run: original config/assets with `--no-bundle --outdir /tmp/<unique> --outfile /tmp/<unique>.multipart`. Ordinary bundled dry-run attempts failed creating repository-local .wrangler/tmp directories on the read-only filesystem. These metadata checks do not prove bundle validity.

The 20 Edge application units inherit the complete top-level Observability block in every declared env (local/development/vpc/test as applicable). No env-specific Observability overrides were found. Jump staging already has a complete explicit block and both sampling fields were updated there; inheritance is not needed for staging. Away and Busy have no named envs. Local and test retain collection settings rather than being disabled.
