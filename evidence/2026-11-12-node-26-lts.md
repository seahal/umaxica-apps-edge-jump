# Node 26 LTS toolchain verification

Both Jump and Away now pin Node 26.13.1 and pnpm 12.18.0 in `mise.toml`.
`package.json` engines and README instructions match the Node pin. Existing
CI reads `engines.node`, so it follows the same version. No deployment occurred.

Official https://nodejs.org/dist/index.json reported v26.13.1, dated
2026-11-10, as the newest Node 26 release with LTS label Lithium.
`mise install` installed the release; `mise exec -- node --version` returned
v26.13.1 in both repositories.

Under the new toolchain, both repositories passed `format:check`, `lint:check`,
`typecheck`, `test:e2e`, and `cloudflare:check` (dry run).
Jump passed `test` (2,217 tests) and E2E (36 tests).
Away passed `test:cov` (152 tests, coverage thresholds met), E2E (4 tests),
and `test:worker`. Jump's previously observed missing direct Miniflare dependency
was not changed or revalidated as part of this toolchain update.
