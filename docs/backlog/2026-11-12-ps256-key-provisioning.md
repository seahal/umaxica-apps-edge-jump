# PS256 鍵設定の履歴と残作業

記録日: 2026-11-12
状態: 本番鍵の設定・デプロイは未実施

## 経緯

オーナーの指示により、Jump を PS256 専用に変更した。ES384 の互換性は不要とされ、
旧方式の署名・検証処理と `wrangler.jsonc` 内の EC 公開鍵設定を削除した。
公開鍵・秘密鍵は RSA 3072 bit、公開指数 65537 を使用する。

コード、鍵生成スクリプト、現行仕様書とテストは更新済み。
本番の秘密鍵、Cloudflare の設定、Cosmos 側の鍵や実装は変更していない。
検証用の一時鍵生成は実施したが、本番用の鍵は生成していない。

## デプロイ前の残作業

- 本番用の新しい PS256 鍵ペアと一意の `kid` を用意する。
- Workers secret に PKCS#8 秘密鍵を設定する。
- `UMAXICA_JUMP_PRIVATE_KEY_KID` と `UMAXICA_JUMP_PUBLIC_JWKS` を設定し、
  公開鍵と秘密鍵の対応を確認する。
- Cosmos 側の送信署名と Jump 返却トークンの検証を PS256 に揃える。
- 本番反映後に PS256 の往復と旧 ES384 トークンの拒否を確認する。

外部設定の変更は、引き継ぎの規則に従い実施直前にオーナーへ確認する。
この記録は鍵設定やデプロイの完了を意味しない。秘密鍵や秘密値は記録しない。
